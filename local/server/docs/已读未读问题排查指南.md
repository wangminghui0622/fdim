## 常见问题排查

### 问题1：A发消息后一直显示"未读"
**可能原因**：
1. B没有调用 `markConversationMessageAsRead`
2. 后端没有发送 `HasReadReceipt`
3. A没有收到 `HasReadReceipt` 通知
4. A收到通知但没有更新UI

**排查步骤**：
1. 检查B端日志是否有 `[Chat] Marking message as read`
2. 检查后端日志是否有 `Sending HasReadReceipt notification`
3. 检查A端日志是否有 `[Chat] Received read receipt`
4. 检查A端 `_onReadReceipt` 方法是否正确更新消息状态

### 问题2：B进入聊天页面后，会话列表未读数不消失
**可能原因**：
1. 后端没有发送 `ConversationUnreadChangeNotification`
2. B没有处理 contentType 1702 通知
3. 会话列表没有刷新

**排查步骤**：
1. 检查后端日志是否有 `Sending ConversationUnreadChange notification`
2. 检查B端日志是否有 `[SDK] Conversation notification received`
3. 检查 `im_manager.dart` 的 case 1702 是否触发
4. 检查会话列表是否监听 `conversationChangedSubject`

### 问题3：FocusDetector 不工作
**可能原因**：
1. 依赖版本不对
2. 消息没有被 FocusDetector 包装
3. `onVisibilityGained` 没有触发

**排查步骤**：
1. 确认 `pubspec.yaml` 中有 `focus_detector_v2: ^3.1.0+1`
2. 运行 `flutter pub get`
3. 检查 `_buildMessageItem` 是否返回 `FocusDetector` widget
4. 添加日志到 `onVisibilityGained` 和 `onVisibilityLost`
