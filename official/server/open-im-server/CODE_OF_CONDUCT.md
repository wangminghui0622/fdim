这是 OpenIM 项目的行为准则（Code of Conduct），基于 Contributor Covenant 2.0。以下是各部分说明：
文件结构说明
1. 我们的承诺（Our Pledge）
目标：营造无骚扰的参与环境
覆盖：所有成员、贡献者和领导者
原则：无论年龄、体型、残疾、种族、性别、经验、教育、社会经济地位、国籍、外貌、种族、宗教、性取向等，都应受到尊重
2. 我们的标准（Our Standards）
鼓励的行为：
展现同理心和善意
尊重不同意见、观点和经验
给予并接受建设性反馈
承担责任，为错误道歉并改进
关注社区整体利益
禁止的行为：
性化语言或图像，性骚扰
恶意评论、人身攻击、政治攻击
公开或私下骚扰
未经许可发布他人隐私信息
其他不专业的行为
3. 执行责任（Enforcement Responsibilities）
社区领导者负责澄清和执行标准
有权删除、编辑或拒绝不符合准则的内容
会说明处理原因
4. 适用范围（Scope）
适用于所有社区空间
也适用于代表社区时的公开场合（如官方邮箱、社交媒体、活动）
5. 举报机制（Enforcement）
举报邮箱：security@openim.io
承诺：及时、公平地审查和调查
保护举报人隐私和安全
6. 执行指南（Enforcement Guidelines）
按严重程度分为 4 级：
级别 1：纠正（Correction）
情况：使用不当语言或不专业行为
处理：私下书面警告，说明违规原因，可能要求公开道歉
级别 2：警告（Warning）
情况：单次或系列违规
处理：警告并限制与相关人员互动，包括社区空间和外部渠道（如社交媒体），持续违规可能被临时或永久封禁
级别 3：临时封禁（Temporary Ban）
情况：严重违规或持续不当行为
处理：临时禁止与社区的任何互动和公开交流，包括与相关人员及执行者的互动
级别 4：永久封禁（Permanent Ban）
情况：持续违规、骚扰个人或群体、攻击或贬低特定群体
处理：永久禁止在社区内的任何公开互动
总结
这份行为准则旨在：
营造友好、包容的社区环境
明确可接受与不可接受的行为
提供清晰的举报和处理机制
保护所有参与者的权益
这是开源项目的常见做法，有助于维护健康的协作环境。
